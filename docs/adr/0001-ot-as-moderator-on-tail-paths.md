# ADR-0001：過度旅遊認知定位為調節變數，打在「整體意圖→五大分項意圖」尾端五條路徑

日期：2026-08-28
狀態：已採納

## 背景

原草稿 H1~H3 將過度旅遊認知（OT）設為前置變數，直接影響態度/主觀規範/PBC。此設計違反 Ajzen 的 TPB 規範——外部背景因素須透過信念層間接作用，直接畫箭頭需要額外辯護。

考慮過的方案：
- **A（採納）**：OT 為調節變數，調節 GTBI→五大分項意圖的五條尾端路徑
- **B**：OT 調節 A/SN/PBC→GTBI 的中段三條（TPB 調節研究的標準位置，前例最多）
- **C**：OT 改為前置，走 OT→信念→態度們的完整因果鏈（理論最正統）
- **D**：兩層都調節（八條調節假設）

## 決策

採 A。OT 認知以多群組 SEM 檢驗（高/低 OT 兩組，比較五條路徑係數差異；AMOS 原生支援）。舊 H1~H3 全數廢除。

## 理由

1. 研究摘要的核心承諾是「分析哪一類行為最易受過度旅遊情境影響」——調節打在五條分項路徑正是這句話的直接統計翻譯；B 案只能用描述性比較間接回答。
2. 「情境下」的題意本質就是調節語感：OT 體驗改變整體綠色意願落實到各領域的傾向。
3. 驗法（多群組 SEM）與 B 案完全相同，不增加操作難度，符合「中規中矩且簡單」的方法學需求。

## 代價與風險

- 文獻前例比 B 案少，第二章需自行建構一小節論證（擁擠/情境限制作為 intention→behavior 落實層調節的文獻彈藥，由 research agent 蒐集，見 docs/research/）。
- 多群組 SEM 切組損失檢定力，樣本目標由 300~500 上修為 400+。
- 若 research agent 查回的前例密度過低，退回 B 案的成本是重寫 H6 一節與第二章一小節，問卷不受影響（OT 量表兩案通用）。
